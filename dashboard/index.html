SimCLR Self-Supervised Pre-Training — Contribution 2
Stage 2 · NT-Xent contrastive loss on unlabelled Nigerian-augmented sequences · τ=0.5 · Section 3.10.2 Component 3
What this solves: "acute annotation scarcity in which over 80% of sensor data remains unlabelled." SimCLR learns degradation-robust representations from unlabelled target sequences by maximising agreement between augmented views — no RUL labels required. Pre-trained weights warm-start Stage 3 (train.py).
