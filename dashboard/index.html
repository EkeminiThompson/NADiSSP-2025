Three Layers of Heterogeneity (Chapter 1.2)
1. Asset Heterogeneity
Four equipment classes with different physics, sensor profiles, failure modes, and degradation timescales (20–130 cycles). A model trained on turbines cannot transfer to ESP pumps — pressure-drop patterns do not generalise to vibration-current patterns.
2. Temporal Heterogeneity
Legacy 1970s equipment reports data intermittently (sampling mismatch) while modern IoT-instrumented offshore platforms stream at 1Hz. Same physical degradation produces completely different data shapes depending on installation era.
3. Environmental Heterogeneity
Nigerian operating conditions impose 6 perturbations absent from global benchmarks: humidity drift, telemetry dropout (power outages), sabotage impulses (pipeline vandalism), corrosion baseline shifts, sampling mismatches, and wave loading.
NADiP Response to Each Layer
GRL Adversarial Alignment
Gradient reversal forces the encoder to learn features that are domain-invariant across all four asset classes. Domain discriminator accuracy reduced to 41.6% (near-chance) — proving the representations generalise.
SimCLR Contrastive Augmentation
Physics-informed augmentation (all 6 perturbations) during contrastive pre-training teaches the model to recognise the same degradation signal regardless of sampling rate, dropout, or corrosion noise.
Weibull PH Head
Asset-class-specific shape parameter β>1 models the wear-out regime. Different assets have different failure timescales — the Weibull head learns this per-class rather than assuming one fixed curve.
Proof of Heterogeneous Generalisation — Single Model, All Four Asset Classes (Table 4.6)
The key claim: one NADiP model trained jointly achieves AUPRC ≥ 0.85 on all four asset classes simultaneously — without retraining per asset. This is the definition of heterogeneous generalisation.
